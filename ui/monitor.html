Sitemap Monitor

Watches the bio-dedicated child sitemaps of the sites you add (e.g. agents-sitemap.xml), and on a schedule diffs each one's URL set against the stored baseline. A new bio URL = a candidate new hire (auto-extracted into the Master Database); a departed URL = a candidate departure. Unchanged child sitemaps are skipped via <lastmod>, so a pass costs almost nothing.

We auto-find each site's sitemaps (robots.txt), keep only the children that are dedicated to people pages, and seed their current roster as the baseline (no alerts for the existing roster — only future changes are flagged).
